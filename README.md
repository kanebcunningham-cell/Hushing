# HUSHING — Kane Cunningham

## A Creative Methodology for Painting Place from the Inside

**HUSHING** is a landscape painting methodology developed by British artist **Kane Cunningham**.

Hushing describes a process in which knowledge of landscape — accumulated through research, walking, observation, history, memory and direct experience — is released through the physical process of abstract painting.

**The painting is not an appearance of the landscape but an expression of the place.**

The methodology takes its name from the historic practice of **hushing**, in which water was accumulated and suddenly released across a landscape to expose the ground beneath.

Within Cunningham's painting methodology, this becomes:

**Accumulation → Impoundment → First Strike → Release → Entrainment → Deposition → Aftermath**

Central ideas within HUSHING include:

* Painting Place from the Inside
* Process as Carrier of Place
* Earned Visual Language
* Dynamic Landscape Principle
* Accumulation
* Impoundment
* River-Ground
* The First Strike
* Release
* Entrainment
* Deposition
* The Deposition Test
* The Aesthetic of Aftermath
* Do Not Repair the Aftermath
* Personal Hushing

The methodology is set out in the essay:

**HUSHING: A Creative Methodology for Painting Place from the Inside — Against the Picturesque: Upper Wharfedale**

**Author: Kane Cunningham**
**2026**

This repository provides the published HUSHING methodology and supporting material relating to its application to contemporary abstract landscape painting.
